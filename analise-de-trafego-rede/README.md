# 🚨 Cybersecurity Incident Report: Network Traffic Analysis

🇺🇸 English | 🇧🇷 [Versão em Português](README.pt-br.md)

## 🎯 Objective
Analyze network traffic in transit (DNS and ICMP) using a network protocol analyzer tool (`tcpdump`) to investigate a cybersecurity incident and identify the affected network protocols and services.

## 📝 Scenario
Customers reported an inability to access the client's website (`www.yummyrecipesforme.com`), receiving a "destination port unreachable" error. The investigation required capturing network packets to determine the root cause of the connection failure between the browser's UDP requests and the DNS server's ICMP responses.

## 🛠️ Skills & Tools Demonstrated
* **Packet Sniffing & Analysis:** `tcpdump`
* **Protocols:** TCP/IP, UDP, ICMP, DNS (Port 53)
* **Incident Response:** Log analysis and formal incident reporting.

## 📄 Project Documentation

* **[Incident Report: Network Traffic Analysis (PDF)](./incident-report-network-traffic.pdf):** A formal incident report detailing the time of the event, the methodology used to analyze the `tcpdump` logs, key findings regarding the unreachable DNS port, and the likely cause of the incident.
