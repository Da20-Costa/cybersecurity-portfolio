# 🛡️ Security Automation: File Updates in Python

🇺🇸 English

## 🎯 Objective
Develop a Python algorithm to automate the process of parsing, auditing, and updating network access control lists (allow lists) by removing unauthorized IP addresses.

## 📝 Scenario
As a security professional, I was tasked with regularly updating an IP allow list file controlling access to restricted patient records. To streamline this process and reduce human error, I wrote a Python script that compares the current allow list against a list of employees whose access needs to be revoked, automatically removing their IPs and rewriting the updated security file.

## 🛠️ Skills & Functions Demonstrated
* **File Handling:** Utilizing `with open()`, `.read()`, and `.write()` to safely access and modify system text files.
* **String & List Manipulation:** Using `.split()` to parse file data into iterables and `.join()` to reformat data for storage.
* **Iterative Logic:** Constructing `for` loops and `if` conditional statements to systematically check for and `.remove()` unauthorized network addresses.
* **Security Automation:** Translating a manual access control task into an automated, programmatic solution.

# 🛡️ Automação de Segurança: Atualização de Ficheiros com Python

🇧🇷 Versão em Português

## 🎯 Objetivo
Desenvolver um algoritmo em Python para automatizar o processo de análise, auditoria e atualização de listas de controlo de acesso à rede (allow lists), removendo endereços IP não autorizados.

## 📝 Cenário
Como profissional de segurança, fui encarregado de atualizar regularmente um ficheiro de permissões de IP que controla o acesso a registos restritos de pacientes. Para otimizar este processo e reduzir erros humanos, criei um script em Python que compara a lista de permissões atual com uma lista de funcionários cujo acesso deve ser revogado, removendo automaticamente os seus IPs e reescrevendo o ficheiro de segurança atualizado.

## 🛠️ Competências e Funções Demonstradas
* **Manipulação de Ficheiros:** Utilização de `with open()`, `.read()` e `.write()` para aceder e modificar ficheiros de texto do sistema de forma segura.
* **Manipulação de Strings e Listas:** Uso de `.split()` para converter dados do ficheiro em elementos iteráveis e `.join()` para reformatar os dados para armazenamento.
* **Lógica Iterativa:** Construção de ciclos `for` e declarações condicionais `if` para verificar sistematicamente e `.remove()` (remover) endereços de rede não autorizados.
* **Automação de Segurança:** Tradução de uma tarefa manual de controlo de acesso para uma solução automatizada e programática.
