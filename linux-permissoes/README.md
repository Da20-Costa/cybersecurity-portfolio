# 🛡️ Linux File Permissions & Authorization

🇺🇸 English

## 🎯 Objective
Examine and manage file and directory permissions on a Linux file system to enforce authorization policies and the principle of least privilege.

## 📝 Scenario
As a security professional supporting a research team, I conducted an audit of a shared directory. The audit revealed misconfigured permissions, including unauthorized write access for external users and improper execution rights on confidential directories. Using the Linux command line, I modified these permissions to secure the research data.

## 🛠️ Skills & Tools Demonstrated
* **Command Line Interface (CLI):** Advanced use of Linux commands.
* **Access Control:** Analyzing output from `ls -la` to decode 10-character permission strings.
* **Privilege Management:** Modifying user, group, and other permissions using absolute and symbolic modes with `chmod`.
* **System Hardening:** Securing hidden system files and revoking unauthorized execution/write access.

# 🛡️ Permissões de Ficheiros e Autorização no Linux

🇧🇷 Versão em Português

## 🎯 Objetivo
Examinar e gerir permissões de ficheiros e diretórios num sistema de ficheiros Linux para impor políticas de autorização e o princípio do menor privilégio.

## 📝 Cenário
Como profissional de segurança a apoiar uma equipa de pesquisa, conduzi uma auditoria num diretório partilhado. A auditoria revelou permissões mal configuradas, incluindo acesso de escrita não autorizado para utilizadores externos e direitos de execução inadequados em diretórios confidenciais. Utilizando a linha de comandos do Linux, modifiquei estas permissões para proteger os dados da pesquisa.

## 🛠️ Competências e Ferramentas Demonstradas
* **Interface de Linha de Comandos (CLI):** Uso avançado de comandos Linux.
* **Controlo de Acesso:** Análise do output de `ls -la` para descodificar strings de permissão de 10 caracteres.
* **Gestão de Privilégios:** Modificação de permissões de utilizador, grupo e outros utilizando os modos absoluto e simbólico com `chmod`.
* **Hardening de Sistemas:** Proteção de ficheiros de sistema ocultos e revogação de acessos não autorizados de escrita e execução.
