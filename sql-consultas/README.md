# 🛡️ Security Data Investigation with SQL

🇺🇸 English

## 🎯 Objective
Investigate potential security incidents by extracting and analyzing data from internal employee and login attempt databases using SQL queries.

## 📝 Scenario
Following reports of suspicious network activity and after-hours login failures, I utilized SQL to query relational databases. The goal was to identify compromised accounts based on date, time, and geographic location, and to locate specific employee machines requiring critical security updates across different departments and office buildings.

## 🛠️ Skills & Tools Demonstrated
* **Database Querying:** Advanced use of SQL syntax (`SELECT`, `FROM`, `WHERE`).
* **Data Filtering:** Applying logical operators (`AND`, `OR`, `NOT`) to narrow down security events.
* **Pattern Matching:** Utilizing the `LIKE` operator with wildcards (`%`) for partial string matching in geographic and office location data.

# 🛡️ Investigação de Dados de Segurança com SQL

🇧🇷 Versão em Português

## 🎯 Objetivo
Investigar potenciais incidentes de segurança extraindo e analisando dados de bases de dados internas de funcionários e tentativas de login usando consultas SQL.

## 📝 Cenário
Na sequência de relatórios sobre atividade suspeita na rede e falhas de login fora do horário de expediente, utilizei SQL para consultar bases de dados relacionais. O objetivo foi identificar contas comprometidas com base na data, hora e localização geográfica, e localizar máquinas específicas de funcionários que exigiam atualizações de segurança críticas em diferentes departamentos e edifícios.

## 🛠️ Competências e Ferramentas Demonstradas
* **Consultas a Bases de Dados:** Uso avançado de sintaxe SQL (`SELECT`, `FROM`, `WHERE`).
* **Filtragem de Dados:** Aplicação de operadores lógicos (`AND`, `OR`, `NOT`) para refinar eventos de segurança.
* **Correspondência de Padrões:** Utilização do operador `LIKE` com caracteres curinga (`%`) para correspondência parcial de strings em dados geográficos e de localização de escritórios.
