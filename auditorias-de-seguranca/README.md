# 🛡️ Auditoria de Segurança: Botium Toys

Este diretório contém uma auditoria de segurança simulada realizada para a empresa fictícia Botium Toys. 

## 🎯 Objetivo
Avaliar os ativos de TI, identificar riscos e preencher um checklist de controles e conformidade (PCI DSS, GDPR, SOC) para melhorar a postura de segurança da organização.

## 📄 Documentação do Projeto

1. **[Relatório de Escopo, Objetivos e Avaliação de Riscos (PDF)](./escopo-e-riscos-botium-toys.pdf):** * Documento inicial detalhando a infraestrutura atual da empresa, os ativos geridos pelo departamento de TI e a avaliação das vulnerabilidades existentes.

2. **[Checklist de Controles e Conformidade (PDF)](./auditoria-botium-toys.pdf):** * A auditoria preenchida com base na avaliação de riscos, incluindo um conjunto de recomendações estratégicas para mitigar falhas e alinhar a empresa aos padrões internacionais de segurança.
