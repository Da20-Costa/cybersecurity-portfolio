# 🛡️ Security Risk Assessment: Network Hardening

🇺🇸 English

## 🎯 Objective
Conduct a security risk assessment following a major data breach scenario to identify critical network vulnerabilities and propose effective hardening strategies.

## 📝 Scenario
A social media organization suffered a breach exposing customer PII. An audit revealed poor security hygiene: shared employee passwords, default database administrative credentials, unconfigured firewall rules, and a lack of Multi-Factor Authentication (MFA).

## 🛠️ Skills & Concepts Demonstrated
* **Risk Assessment:** Identifying and prioritizing infrastructure vulnerabilities.
* **Network Hardening:** Proposing actionable defenses including IAM, MFA enforcement, and Firewall ACL configuration.
* **Security Governance:** Establishing implementation frequencies and compliance policies for credential management.

# 🛡️ Avaliação de Risco: Network Hardening

🇧🇷 Versão em Português

## 🎯 Objetivo
Conduzir uma avaliação de risco de segurança após um cenário de vazamento de dados corporativos para identificar vulnerabilidades críticas na rede e propor estratégias eficazes de endurecimento (hardening).

## 📝 Cenário
Uma organização de redes sociais sofreu uma violação que expôs dados pessoais de clientes. Uma auditoria revelou práticas de segurança inadequadas: partilha de senhas entre funcionários, credenciais administrativas de base de dados padrão, firewalls sem regras de filtragem e ausência de Autenticação Multifator (MFA).

## 🛠️ Competências e Conceitos Demonstrados
* **Avaliação de Risco:** Identificação e priorização de vulnerabilidades de infraestrutura.
* **Network Hardening:** Proposição de defesas acionáveis, incluindo IAM, imposição de MFA e configuração de regras de Firewall (ACLs).
* **Governança de Segurança:** Estabelecimento de frequências de implementação e políticas de conformidade para gestão de credenciais.
